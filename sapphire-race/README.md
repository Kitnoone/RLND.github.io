# Сапфировая гонка

Полная копия версии 22 сайта https://sapphire-race-engine.kittyty.chatgpt.site/, опубликованной 5 октября 2026 года.

Исходный коммит: `35cd216ea607c7b6d64c37fd8db7265ddd9c6b05`.

## Запуск

Сайт статический, сборка и npm не требуются. Из папки `sapphire-race` запустите:

```sh
python -m http.server 8080
```

Откройте http://localhost:8080/dist/ . Простое открытие файла через file:// может ограничить работу браузерных функций.

## Состав

- `dist/` — сайт, карты, токены, звуковой движок и анимации. Звуки создаются в браузере через Web Audio.
- `dist/assets/` — все ресурсы сайта, включая сохранённые GIF и атлас предыдущих вариантов.
- `rules/canon-v22.txt` — текст каноничного документа правил.
- `rules/interpretations-v22.md` — временные трактовки условий, не уточнённых в документе.
- `tests/` — проверки механик, экипажа, дистанций и анимаций.
- `CREW-v18.md` — описание импорта персонажей и экипажа.

## Проверки

```sh
node tests/canon-v22.mjs
node tests/rules-v9.mjs
node tests/crew-v18.mjs
node tests/distance-v11.mjs
node tests/animations-v10.mjs
```

Прогресс гонки хранится в браузере, в localStorage; сохранения участников не включены в этот перенос.
